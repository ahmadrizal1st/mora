# Product Vision — Vista & Mora

> **Version:** 1.1.0 | **Updated:** 2026-04

## Visi
**Vista & Mora — Financial Network Ecosystem (MVP)**

## Target User

| App | Target | Platform |
|:----|:-------|:---------|
| **Vista** | HR & Finance Perusahaan (B2B Dashboard) | Web + Desktop App |
| **Mora** | Karyawan (B2C Personal Finance) | Web + Mobile App |

## Platform Strategy
- **Pendekatan:** Web-first, deployable ke Android/iOS/Desktop via **Capacitor**
- **Vista:** Web browser + Desktop app (Capacitor)
- **Mora:** Web browser + Mobile app (Capacitor → Android & iOS)

## Problem Statement
Sistem HR dan keuangan personal yang terpisah dan rumit.

## North Star Metric
Akurasi payroll dan adopsi budgeting PWA.

## Roadmap MVP
1. **Phase 1:** Core API Laravel (Payroll, HR, Wallet)
2. **Phase 2:** Frontend Vista (HR) & Mora (Karyawan) dengan Tabler UI
3. **Phase 3:** AI Categorization (Gemini)
