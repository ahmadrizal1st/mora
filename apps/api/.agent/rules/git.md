# Aturan Git & Workflow

Demi menjaga riwayat kolaborasi dan perubahan versi yang bersih, gunakan konvensi berikut.

## 1. Penulisan Pesan Commit (Conventional Commits)
Format: `<type>(<scope>): <deskripsi>`
Contoh:
- `feat(auth): tambah endpoint login JWT`
- `fix(model): perbaiki relasi User dan Debt`

## 2. Branching Strategy
- Fitur baru: `feature/<nama-fitur>`
- Bug fix: `fix/<nama-bug>`
